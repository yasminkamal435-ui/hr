
# HR Analytics Dashboard

## Overview

This project is an HR Analytics Dashboard designed to analyze employee absenteeism and workforce-related metrics through data analysis and interactive reporting.

The project follows the complete data analytics workflow, starting from raw data storage and preparation, moving through data analysis, and ending with an interactive Power BI dashboard for visualization and decision-making support.

---

## Objectives

* Analyze employee absenteeism patterns.
* Explore workforce-related characteristics.
* Monitor key HR performance indicators.
* Transform raw data into actionable insights.
* Build an interactive dashboard for data exploration.

---

## Dataset

The project uses the **Absenteeism at Work Dataset**, which contains employee absenteeism records and workforce-related attributes such as:

* Age
* Service Time
* Education
* Transportation Expenses
* BMI
* Social Habits
* Absenteeism Hours
* Reasons for Absence
